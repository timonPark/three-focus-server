## 미해결 이슈

### 서버 컨테이너 restart 문제
- 증상: 배포는 성공하나 `three_focus_server` 컨테이너가 계속 재시작
- 에러: `Failed to configure a DataSource: 'url' attribute is not specified`
- `cat ~/app/.env` 확인 결과 DB_HOST, DB_NAME, DB_USER, DB_PASSWORD는 정상 기록됨
- 미확인: `docker compose config`로 compose 최종 설정값 확인 필요
- 의심 원인: .env → docker-compose → 컨테이너로 환경변수 전달 과정 문제
